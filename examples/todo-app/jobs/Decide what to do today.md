At the start of the day, someone wants to turn an open-ended backlog of [[Task]]s into a short, finishable plan. The switch is from working off the whole list to choosing a small set for today, informed by what's due, and checking those off as the day goes.

## Tasks

1. Review open [[Task]]s, with anything due soon surfaced first — reads [[Task]], [[List]]
2. Pull a handful into today — updates [[Task]]
3. Push anything left over from yesterday forward or back to the backlog — updates [[Task]]
4. Check off tasks as they get done — updates [[Task]]

See [[Plan today]] for the detailed step-by-step.

## Success criteria

- Most tasks planned for a day are done that day.
- Overdue tasks are a rare exception, not a standing count.
